# Semantic HTML5 & Accessible Component Architecture

Responsive enterprise dashboard starter using semantic HTML5, accessible navigation, data tables, forms, and a native modal dialog.

## Run
Open `index.html` in a browser. No installation is needed.

## Structure
- `index.html` — dashboard structure and semantic components
- `assets/styles.css` — responsive styling and visible focus indicators
- `assets/app.js` — accessible mobile navigation and modal behavior
- `components/README.md` — component architecture notes

## Validation
Run `index.html` through the W3C Nu HTML Checker: https://validator.w3.org/nu/ . Confirm the result is error-free before claiming validator approval. Keyboard-test the skip link, menu, form, and modal.

This is a front-end starter; form submission is a demonstration and no backend is connected.
