# Component architecture

Implemented in `../index.html`:
- Header and labelled primary navigation
- Sidebar navigation inside an `<aside>` landmark
- KPI cards using `<article>`
- Data table with caption and scoped column/row headers
- Form with labels, fieldset, legend, required and email validation
- Native `<dialog>` modal with an accessible title

Use logical heading levels, visible focus indicators, and accessible names for controls.
